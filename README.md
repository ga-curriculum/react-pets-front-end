# ![[React Front End Pets Lab]](./assets/tktk-hero.png)

## About

In this lab students will consume from a RESTful API to create, read, update, and delete pet data. Students will use React to build a front end that will allow users to interact with the API as a SPA. This lab is a basic introduction to consuming APIs with React and **does not** include any React Router to change views; instead, students will use conditional rendering to display different views.
